║   CELL EDGE MOVEMENT ANALYSIS GUI - QUICK REFERENCE            ║
╚════════════════════════════════════════════════════════════════╝

┌─ LAUNCHING ────────────────────────────────────────────────────┐
│ python launch_gui.py                                           │
│ or: python cell_edge_analysis_gui.py                           │
└────────────────────────────────────────────────────────────────┘

┌─ WORKFLOW ─────────────────────────────────────────────────────┐
│ 1. Setup & Run Tab:                                            │
│    - Browse -> Select Image Stack (PIEZO1)                     │
│    - Browse -> Select Mask Stack                               │
│    - Configure parameters (or use defaults / presets)          │
│    - Run All Steps (or Run Selected Step)                      │
│ 2. Results Viewer / Statistics / Correlation Analysis tabs     │
│ 3. Help -> Analysis Guide = steps, math & settings             │
│    (hover any control for a tooltip)                           │
└────────────────────────────────────────────────────────────────┘

┌─ KEY PARAMETERS ───────────────────────────────────────────────┐
│ STEP 1 - Data Loading                                          │
│   - Normalize Frames: ON     Scale: 100.0                      │
│   - Norm Reference: max | percentile (robust to hot px)        │
│   - Norm Percentile: 99.9    (used if reference=percentile)    │
│   - Norm Region: frame | mask (mask = in-cell only)            │
│   - Norm Scope: per_frame | global (global=time-consistent)    │
│   - Subtract Background: ON   Percentile: 10                   │
│   - [Robust preset] / [Default preset] buttons                 │
│                                                                │
│ STEP 2 - Edge Detection                                        │
│   - Smooth Edges: ON   Smoothing Sigma: 20.0 (10-40)           │
│                                                                │
│ STEP 3 - Displacement                                          │
│   - Min Movement Pixels: 5     Arrow Scale: 1.0                │
│                                                                │
│ STEP 4 - Classification                                        │
│   - Movement Threshold: 5.0 px (must match Step 9)             │
│                                                                │
│ STEP 5 - Sampling                                              │
│   - Method: displacement_like | fixed_x | dense | per_frame    │
│   - Number of Points: 10   Target Points (disp): ~20           │
│                                                                │
│ STEP 7 - Intensity                                             │
│   - Intensity Statistic: mean | max | percentile               │
│   - Intensity Percentile: 95  (if statistic=percentile)        │
└────────────────────────────────────────────────────────────────┘

┌─ NORMALIZATION: WHY VALUES CAN LOOK LOW ───────────────────────┐
│ Default = each frame / its single brightest pixel, so one      │
│ hot pixel sets '100' and edge MEANS read low (e.g. 2-14).      │
│ ROBUST preset: percentile 99.9 / in-mask / global = a          │
│ stable, cell-based, frame-to-frame-consistent reference.       │
│ (Numbers then differ from default-preset runs.)                │
│ Plot axes state what was used, e.g.                            │
│   PIEZO1 intensity (mean, % of per-frame max)                  │
└────────────────────────────────────────────────────────────────┘

┌─ VISUALIZATION MODES (Results Viewer) ─────────────────────────┐
│ Overview       -> Image, mask, edge overlay                    │
│ Edge Detection -> Edges on image and mask                      │
│ Displacement   -> Displacement maps + statistics               │
│ Classification -> extruding / retracting / stable              │
│ Sampling       -> Sampling rectangle locations                 │
│ Intensity      -> PIEZO1 values (axis labelled w/ method)      │
│ Correlation    -> in the separate Correlation Analysis tab     │
└────────────────────────────────────────────────────────────────┘

┌─ NAVIGATION ───────────────────────────────────────────────────┐
│ |<  First frame     <  Previous frame                          │
│ >   Next frame      >|  Last frame                             │
└────────────────────────────────────────────────────────────────┘

┌─ MOVEMENT CLASSIFICATION ──────────────────────────────────────┐
│ EXTRUDING  -> Edge UP/OUT (negative displacement) [BLUE]       │
│ RETRACTING -> Edge DOWN/IN (positive displacement) [RED]       │
│ STABLE     -> Minimal edge movement [GRAY]                     │
└────────────────────────────────────────────────────────────────┘

┌─ HELP & TOOLTIPS ──────────────────────────────────────────────┐
│ Help -> Analysis Guide : per-step purpose, math, defaults,     │
│   how to change them, sign conventions & glossary.             │
│ Help -> About          : version info.                         │
│ Tooltips: hover file pickers, run buttons, step selector,      │
│   Step 1 & Step 7 params, presets, viewer selectors.           │
└────────────────────────────────────────────────────────────────┘

┌─ OUTPUT FILES ─────────────────────────────────────────────────┐
│ analysis_results/                                              │
│  step1_results/  images.npy, masks.npy, metadata.json          │
│  step2_results/  edges.pkl                                     │
│  step3_results/  displacement_data.pkl                         │
│  ... step9_results/  correlation_results + scatter_plot.png    │
│  each stepN_results/ has a verification_figures/ folder        │
└────────────────────────────────────────────────────────────────┘

┌─ TROUBLESHOOTING ──────────────────────────────────────────────┐
│ GUI won't start: need Python 3.7+ with Tkinter                 │
│   pip install -r requirements.txt (Linux: python3-tk)          │
│ Analysis fails: check Log; verify TIFFs; match dims            │
│ 'No valid displacements': check edges; raise sigma             │
│ Intensities look low: use the Robust preset (Step 1)           │
└────────────────────────────────────────────────────────────────┘

┌─ COMMAND-LINE ALTERNATIVE ─────────────────────────────────────┐
│ python run_all_steps.py --batch       (all datasets)           │
│ python step1_data_loading.py --help   (all options)            │
│ Robust norm (step1): --normalization-method percentile         │
│   --normalization-region mask --normalization-scope global     │
│ Bright puncta (step7): --intensity-statistic max               │
└────────────────────────────────────────────────────────────────┘

┌─ RECOMMENDED IMAGE SPECS ──────────────────────────────────────┐
│ Multi-frame TIFF, 8/16-bit grayscale                           │
│ Image and mask stacks must match in size & frame count         │
└────────────────────────────────────────────────────────────────┘
